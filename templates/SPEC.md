# SPEC　專案規格（規劃用）

> 狀態：規劃中／已確認（YYYY-MM-DD）／開發中（擇一）
> 開新專案時先寫本檔，使用者確認後才開始寫程式；在 claude.ai 網頁或任何 coding agent 撰寫都照本範本。
> 用法：
> 1. 開始寫程式時：從 `templates/` 建立 `AGENTS.md`、`README.md`、`PROGRESS.md`，照第十節把「開始寫程式時」的內容搬過去，原處改寫「（已搬到 X）」，同一件事不留兩份。
> 2. 第一版完成前：本檔是「要做什麼」的依據，需求有變就改本檔；進度寫在 `PROGRESS.md`。
> 3. 第一版必做功能全部完成、使用者實測確認後：照第十節搬完其餘內容，經使用者同意後刪除本檔（搬移與刪除同一次 commit）。

## 一、目標與使用者

- 要解決的問題：例：每天收盤後手動抄籌碼資料太花時間
- 誰在用、什麼情境用：例：自己，收盤後在住家開發機執行
- 做到什麼程度算成功：例：一鍵產生當天的籌碼表

## 二、功能清單

| 編號 | 功能 | 分類 | 說明 |
|---|---|---|---|
| F1 | 例：下載當日籌碼資料 | 必做 | 例：來源見第四節 |
| F2 | 例：匯出 Excel | 必做 | |
| F3 | 例：LINE 通知 | 之後再做 | 第一版不做 |

- 不做的事（明確排除，避免 AI 多做）：例：不做自動下單

## 三、操作流程與畫面

1. 例：雙擊 `start.bat` → 選日期 → 按「產生」→ 開啟 Excel
- 畫面說明或草圖：例：草圖放在 `docs/spec_screen.png`

## 四、資料與業務規則

| 資料 | 來源 | 格式 | 更新頻率 | 範例 |
|---|---|---|---|---|
| 例：三大法人買賣超 | 例：證交所網站 | CSV | 每交易日 | `sample_data/` |

- 外部 API：文件位置、次數或額度限制
- 業務規則：例：只抓上市股票；非交易日不執行
- 機密（API Key、帳密）放 `.env`，不寫進本檔

## 五、目標執行環境

- 開發在：住家開發機／公司開發機
- 執行在：例：住家開發機（見全域規則「電腦環境」）
- 公司專案：同事電腦要不要免安裝
- AI 工具安全分流：是否套用 Claude Code 資安防凍結規則（是：交由 Antigravity 等其他 agent 處理，並加入 `permissions.deny`／否：一般專案）

## 六、技術選擇

| 項目 | 選擇 | 理由 |
|---|---|---|
| 語言 | 例：Python 3 | 沒有特別理由時用 Python |
| 框架／套件 | 例：requests、openpyxl | |
| 需要另外安裝的東西 | 例：無 | |

## 七、驗收方式

- 第一版完成的條件：例：F1、F2 完成，連續 3 個交易日產出正確
- 使用者怎麼測、預期看到什麼：例：執行後 `output/` 出現當天的 Excel，數字與證交所網站一致

## 八、待決定

1. 例：要不要保留歷史資料？保留幾天？

## 九、開發步驟（交給 coding agent 的順序）

1. 從 `templates/` 建立 `AGENTS.md`、`README.md`、`PROGRESS.md`、`.gitignore`，照第十節搬移
2. 例：F1 下載資料，用 `sample_data/` 驗證
3. 例：F2 匯出 Excel

- 每一步都要能單獨驗證。

## 十、搬移對照

| 本檔章節 | 搬到 | 時機 |
|---|---|---|
| 四、業務規則；五、目標執行環境 | `AGENTS.md`「業務規則」「目標執行環境」 | 開始寫程式時 |
| 七、驗收方式 | `AGENTS.md`「修改後的驗證方式」 | 開始寫程式時 |
| 六、技術選擇 | `PROGRESS.md`「使用者已確認的事」 | 開始寫程式時 |
| 八、待決定（還沒決定的） | `PROGRESS.md`「待使用者決定」 | 開始寫程式時 |
| 九、開發步驟 | `PROGRESS.md`「下一步」 | 開始寫程式時 |
| 一、目標；三、操作流程 | `README.md`「用途」「操作方式」 | 第一版驗收後 |
| 二、「之後再做」的功能 | `PROGRESS.md`「下一步」或「待使用者決定」 | 第一版驗收後 |
| 四、資料來源與格式 | `README.md` 或 `AGENTS.md`（給 AI 用的寫 `AGENTS.md`） | 第一版驗收後 |

- 沒有 `PROGRESS.md` 的小專案：要搬到 `PROGRESS.md` 的內容改寫進 `README.md`。
